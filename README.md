# Estatistical-Evaluation-of-AI-Systems-
From intuition to evidence in AI.
🇪🇸 Español

Un laboratorio de investigación donde la inteligencia artificial deja de ser una caja negra y se convierte en un sistema medible, analizable y optimizable. Aquí, la estadística se utiliza para evaluar rigurosamente modelos, experimentos y decisiones, construyendo una base sólida para desarrollar IA más confiable y efectiva.

🇬🇧 English

A research lab where AI stops being a black box and becomes something measurable, analyzable, and optimizable. Here, statistics is used to rigorously evaluate models, experiments, and decisions—building a solid foundation for more reliable and effective AI.
